# Agent guidance — AdventureWorks Excel BI

Start with [REPO_CONTEXT.md](REPO_CONTEXT.md) to locate the authoritative project sources. Read only the documents relevant to the current task; the map is not a status journal.

- **Approval boundary:** Project implementation has been authorized. Do not infer permission for new dataset downloads, publishing, or other external actions solely from a planned task; follow the user's current instructions and prior authorizations.
- **Work tracking:** Live Jira AWBI issues determine task status. The [Jira workflow](docs/JIRA_WORKFLOW.md) defines review and Done; GitHub holds the versioned artifacts and validation evidence.
- **Excel automation:** Check the installed Excel MCP tools and validate real workbook changes by readback before claiming a feature works. See the [AI workflow](docs/AI_WORKFLOW.md).
- **Documentation:** Use the local [Repository Documentation Readability skill](.agents/skills/repository-documentation-readability/SKILL.md). Keep repository documentation in English; communicate with the user in Spanish.
- **Evidence:** Do not present plans as implemented functionality, or AI-generated results as independently verified.
